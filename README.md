# Bai1
Đã cài đặt thành công Node.js phiên bản LTS.
Kiểm tra phiên bản Node.js bằng lệnh node -v và npm bằng lệnh npm -v.
Đã tạo file hello.js và chạy thành công bằng lệnh node hello.js.
CÁCH CHẠY.
Mở Visual Studio Code.
Mở Terminal tại thư mục chứa file hello.js.
Nhập lệnh node hello.js.
Nhấn Enter để thực thi chương trình.
Kết quả: Chương trình chạy thành công và hiển thị 3 dòng thông báo trên Terminal:
Hello World!
